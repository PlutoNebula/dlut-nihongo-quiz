# 计算机组成题库

首页增加一个“计算机组成（软国际）”入口，下设四份试卷。题目沿用现有选择、判断、填空答题流程、错题本、收藏和统计；没有新增阅读模式、主观题评分或独立 AI 答案面板。

| 题库                 | 题目 | 题单 | 来源物理页 |
| -------------------- | ---: | ---: | ---------: |
| 2021期末             |   43 |    9 |          3 |
| 2024期末（部分试卷） |   13 |    3 |          4 |
| C卷（日期待核对）    |   36 |    7 |          5 |
| 期中三年合集         |  107 |    3 |         19 |
| 合计                 |  199 |   22 |         31 |

全部199题均已填写答案和中文解析：134道单选、18道判断、47道填空。原来的5道计算/简答题沿用填空格式；其中2024卷的3道文字简答提供参考答案，现有填空判分仅做文本匹配，不能判断不同措辞的语义等价。

## 答案来源与核对

答案由 StepFun `step-3.7-flash` 通过 `https://api.stepfun.com/step_plan/v1/chat/completions` 生成；全部题目经过第二轮模型审校，并对疑点进行原图、位运算、IEEE 754与MIPS编码核对。这些是生成并校订的参考答案，不是原卷官方答案；`answerProvenance` 统一为 `generated`，未将手写圈选标作标准答案。

复核时修正了题目ID错位、跳转地址与编码字段混淆、浮点/位移说明错误等问题。生成模型、调用记录、数据勘误及程序核对说明见 `data/processed/computer-answer-generation.json`，其中不包含API密钥。

主要原文处理：

- 期中卷段一第26题选项A被遮挡，保留可辨认的十进制193，改为二进制填空；不猜被遮挡的选项。
- 期中卷段一、三第31题的二进制值为00111000，正确十六进制为38，但印刷选项没有正确值；改为填空并保留原卷说明。
- 期中卷段一第22题选项C由OCR的`$0`改为原图的`0`；卷段二第34题C由OCR的9位串改为原图8位的`00110100`。
- C卷乘法器表恢复(5)/(6)所在的LSB位置，并在题干注明原卷第三、四轮操作文案颠倒的勘误。
- 2021卷规格化题明确采用`0.1 ≤ m < 1`的尾数约定，避免两种教材记法造成多个正确选项。

## 维护

- `data/raw/computer-organization/<category>.json`：题库源，包含题干、选项、答案、解析和来源页。
- 同目录`*-coverage.md`与`ocr/`：首次OCR拆题记录及来源证据；这些历史记录中的“答案留空”不代表当前题库状态。
- `public/<category>-question-bank.json`：生成后的应用题库，不直接编辑。

修改题库源后运行：

```bash
npm run parse:computer
npm run generate:meta
npm run test:computer
npm run audit:banks
```

生成器先验证全部四库再写入，检查题目ID、题单、答案与选项一致性、非空解析和逐页覆盖。缺页的2024卷没有补造题目；C卷日期、期中合集卷段年份仍保留待核对标记。原第14页二次OCR失败记录作为历史来源信息保留。
